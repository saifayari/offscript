Kifh Bdet (The History of ML)

1959 • ARTHUR SAMUEL

The Checkers Program That Played Itself

Samuel coined the term "Machine Learning". He didn't write rules for every winning checkers move. He wrote a system that learned by playing thousands of games against its own copies.

The Core Revelation: A machine can discover winning strategies that its creator never explicitly programmed!

The Golden ML Security Law

Garbage In = Vulnerable Out

80% OF THE BATTLE IS DATA

Neural networks are only as sharp as their training labels. If your training dataset includes mislabeled traffic, adversarial evasion is guaranteed.

Data Poisoning: Attackers inject benign-looking exploit samples into your feedback loop.
Feature Engineering: Good features (entropy, token ratios) beat complex architectures every time.

Slide 12 // Prompt Tactic 01

Technique 1 - Role Prompting

× WEAK / VAGUE PROMPT
"Is this Python script secure? Can you check it for bugs?"

Result: Generic high school coding tips. Misses critical vulnerabilities.

✓ STRONG / ROLE PROMPT
"Act as a Senior SOC Analyst. Review this Python script specifically for OWASP Top 10 vulnerabilities. Provide: 1. Vulnerability name & line, 2. Exploit PoC payload, 3. Hardened code."

Result: Primes the AI's specialized security latent space for actionable exploit intelligence.

Slide 13 // Prompt Tactic 02

Technique 2 - Few-Shot Prompting

The AI needs a pattern. Give it 2 concrete examples before giving it the target problem.

Exemplar 1 (Benign): "GET /about.html" → {"classification": "BENIGN"}
Exemplar 2 (Attack): "GET /download?file=../../etc/passwd" → {"classification": "LFI"}
Target Query: "POST /search?q=' UNION SELECT..." → [Model outputs clean JSON with zero fluff]
✓ Forces strict JSON schema output
✓ Eliminates hallucinations in CTF pipelines
Slide 14 // Competition Playbook

3 Golden Rules for AI in CTFs

RULE 01

Never Trust Blindly

Always test AI-generated exploit scripts locally in a sandbox before submitting to scoring engines.

RULE 02

Be Surgical, Not Long

3 specific sentences with clear constraints outperform a 500-word vague prompt every time.

RULE 03

Watch Out For Traps

Target files may contain prompt injections designed to mislead your AI assistant. Sanitize inputs!
